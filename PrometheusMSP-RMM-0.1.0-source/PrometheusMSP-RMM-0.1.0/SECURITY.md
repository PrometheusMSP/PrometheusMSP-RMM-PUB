# Security Policy

This repository is an early MVP and must not be treated as production-ready RMM software. Report suspected vulnerabilities privately to the repository owners through GitHub's private vulnerability reporting feature. Do not include real credentials, private keys, customer telemetry, or exploit data from systems you do not own or have explicit authorization to test.

Include the affected revision, component, reproduction steps using synthetic data, impact, and suggested mitigation. Maintainers should acknowledge a report promptly, coordinate remediation and disclosure, rotate exposed credentials, and preserve relevant audit evidence.

Only test deployments you are authorized to administer. The project does not accept features for credential theft, covert persistence, security-control bypass, evasion, destructive deployment, or unauthorized surveillance.
